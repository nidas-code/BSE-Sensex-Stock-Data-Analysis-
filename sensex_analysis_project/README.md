#  Sensex Analysis Project

This is a C++ project for analyzing historical Sensex stock data from a `.txt` file. It provides various analytical tools like moving averages, volatility checks, trend analysis, and more through a terminal-based menu interface.

---

##  Files Included

- `main.cpp` – Entry point with the interactive menu
- `analysis.cpp / analysis.h` – Functions for statistical and trend analysis
- `data_reader.cpp / data_reader.h` – Loads and parses data from `sensex_data.txt`
- `sensex_data.txt` – Historical stock data (date, open, high, low, close)
- `Makefile` – Automates building and running the program

---
